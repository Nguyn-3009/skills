# skills
All video for marketing skill

Code-drawn marketing videos (9:16 Reels, Shorts, TikTok): every frame drawn on a canvas,
rendered to MP4 in headless Chromium, with voice and sound made in code.

Skills coming here:
- video-engine: the canvas page, seek(t) and the MP4 renderer
- voiceover: voice lines, word timings, captions
- sound-design: sound effects and a music bed made in code
- explainer-reel: voiced story reels
- what-if-short: "what if" shorts with a host character
- pastel-gameplay-ad: no-voice pastel ads with taps, confetti and a "link in bio" ending
